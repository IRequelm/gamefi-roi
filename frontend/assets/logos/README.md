# Opportunity logo assets

Logo files in this directory are local copies of official project assets. Catalog metadata owns the asset path, accessible alt text, and source reference; browser code never maps names to files.

Current proof asset:

- `grass.png` — official Grass horizontal logo from the [Grass media kit](https://www.grass.io/media-kit/).

Add a logo only after verifying an official source and preserving the brand asset without fan art, screenshots, watermarks, or arbitrary third-party packs. Missing metadata should render the parent name without an image.
